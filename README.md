# WCAG 3 Accessibility Pro

This repository contains the source code for the **WCAG 3 Accessibility Pro** WordPress plugin. The plugin helps WordPress sites meet WCAG 3.0 and WCAG 2.2 accessibility standards by providing front‑end tools and admin audits. It requires a single‑use license key validated against a custom backend service.

## Features

- Front‑end accessibility toolbar (font resize, high contrast, text spacing)
- Admin audit tools to check for common WCAG issues
- Licensing system with remote validation
- Optional custom update checker

This codebase is a basic scaffold of the plugin demonstrating how modules are organized. Further development is required for production use.
